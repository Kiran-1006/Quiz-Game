# Quiz Based Question & Answer Page

Welcome to my **Quiz Based Question & Answer Page** project! 🎯

This is a simple and interactive quiz web page where users can answer multiple-choice questions and test their knowledge.

## About The Project

I created this project to practice my **HTML, CSS, and JavaScript** skills while building an interactive web page.

The page presents quiz questions with multiple options, allowing users to select an answer and check their result.

## Features

* 📝 Multiple-choice quiz questions
* 🎯 Interactive question and answer interface
* ✅ Answer selection
* 🔄 Easy to restart the quiz
* 💻 Simple and user-friendly design
* 📱 Responsive layout

## Technologies Used

* **HTML5** – Structure of the webpage
* **CSS3** – Styling and layout
* **JavaScript** – Quiz logic and interactivity
